# Claims

Every factual claim the talk makes, on screen or aloud. QA (or `/redteam`, for a fact-heavy talk) tries to refute each one.

Status:
- **✔** primary source, read directly: the page itself with the sentence quoted, or the artefact the claim is about. A search or tool summary only points to the source; the source earns the ✔
- **◐** secondary only: confirm it, or soften it in the notes
- **⚠** disputed: a real source with a contested framing; present it as a view, both sides in the notes
- **✎** computed: show the working
- **FILL** only the user has it · **CONFIRM** public, but the user confirms it
- **OWN** the speaker's own account: the speaker is the source; QA checks what can be checked

When sources disagree, list and quote both, with the wording the talk uses and why. Resolve every `[TODO …]` marker in the notes (directing.md §7) by the end of the build.
